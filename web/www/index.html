Insert a disk image

Floppy images (.img, .ima, .vfd) and hard disk images, or CD images (.iso) for a CD-ROM drive.

Erase C:

Starts over with an empty C: of the size you pick, and restarts the machine. Everything on C: is lost; download its image first to keep it.

Settings

The settings of the rust-dos.conf file, which this browser keeps. The machine restarts with them; C: stays as it is.
