# The locales of the built-in Windows (`win32_locale`), from which
# tools/gen_locales.py writes src/win32/nls/locales.rs.
#
# Each block is one locale: "[name]" (the setting's value), then one
# "key value" line per field. Lists (days from Monday, months) take "|"
# between their items. A value is a Rust string's contents: \u{A0} is the
# no-break space. "#" starts a comment line.
#
# Where the values come from:
# - LCIDs, ANSI, OEM and Mac code pages: Appendix F, "Locale-Specific
#   Code Page Information", of Nadine Kano's "Developing International
#   Software for Windows 95 and Windows NT" (Microsoft Press, 1995),
#   and Microsoft's published list of locale identifiers ([MS-LCID]).
# - Names, months, days, separators and formats: the Unicode CLDR, with
#   the forms the Windows of the time used where they differ (the
#   language's English name with Windows' qualifier, the three-letter
#   abbreviations of LOCALE_SABBREVLANGNAME, four-digit years in the
#   short date as after Windows 98's year 2000 update), checked against
#   Wine's locale tests where these cover a locale.
# - Currencies: those of 1998, before the euro. Windows 98 SE shipped
#   with each country's own currency; the euro came to these locales'
#   settings with Windows' later updates, not with 98 SE.
#
# fields:
#   lcid, code_pages (ANSI OEM Mac), country_code (LOCALE_ICOUNTRY)
#   full_language (LOCALE_SLANGUAGE), language (LOCALE_SENGLANGUAGE, and
#   setlocale's name with country), abbrev_language, native_language,
#   iso_language, country, abbrev_country, native_country, iso_country,
#   list, measure (0 metric), decimal, thousand, grouping,
#   negative_number, currency, intl_symbol, money_decimal,
#   money_thousand, currency_order (LOCALE_ICURRENCY), negative_currency
#   (LOCALE_INEGCURR), date_separator, time_separator, short_date,
#   long_date, time_format, date_order (0 MDY, 1 DMY, 2 YMD), hours24,
#   am, pm, first_day (0 Monday, 6 Sunday), days, abbrev_days, months,
#   abbrev_months.
#
# The first eight are the locales the setting started with; new ones go
# at the end, since a saved state keeps a locale by its place here.
